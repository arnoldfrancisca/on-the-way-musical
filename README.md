# On The Way — ontwerpconcepten

Drie statische ontwerpen voor een musical-detailpagina. Alle teksten, rollen en praktische gegevens zijn voorbeeldinhoud (voorbeeldtekst), geen bevestigde productiegegevens. Ticketknoppen openen uitsluitend een demo; reserveren of betalen is niet mogelijk.

Dit zelfstandige ontwerpconcept is niet verbonden aan Kortify.

Open de conceptkiezer op de homepage of bekijk `v1/`, `v2/` en `v3/`.
